# USV

## Описание

Проект на Visual C++ 6.0 - модель БЕЗЭКИПАЖНОГО НАДВОДНОГО КОРАБЛЯ (Unmaned Surface Vessel - USV), работающая под управлением основной программы - модельного сервера (world.exe), обрабатывающей методом имитационного моделирования модель распространения гидроакустических сигналов между подводными лодками, торпедами и надводными кораблями в морской подводной среде.

Каждый шаг работы USV разбит на несколько квантов, вырабатываемых сервером:

1. **Квант "перемещение"** — Посылка всем моделям движения объектов. Модели движения вырабатывают новые координаты и параметры движения объектов и передают их в модельный сервер. Получив информацию от моделей движения, модельный сервер формирует новую ситуацию и передает ее в блок формирования гидроакустических полей и сигналов.

2. **Квант "расчет"** — Блок формирует волновую картину возле каждого из объектов и передает ее моделям гидроакустических средств освещения обстановки.

3. **Квант "обработка"** — Модели гидроакустических средств освещения обстановки формируют список обнаруженных целей. Информация от моделей движения и гидроакустических средств освещения обстановки передается в системы управления.

4. **Квант "управление"** — Системы управления основными действиями обрабатывают полученную информацию и формируют команды на изменение режимов работы для моделей движения и моделей гидроакустических средств освещения обстановки, изменяют режимы работы других систем своих объектов, выдают в модельный сервер команды на запуск дополнительных объектов информационной обстановки.

Обмен данными реализован на основе технологии файлов, проецируемых в оперативную память.

## Структура проекта

### Основные файлы

- **MainDoc.cpp/h** — Основной документ приложения (документно-ориентированная архитектура MFC)
- **MainView.cpp/h** — Основное представление документа
- **MainFrm.cpp/h** — Главный фрейм окна приложения
- **FormularDlg.cpp/h** — Диалоговое окно формуляра
- **Functions.cpp/h** — Библиотека функций для вычислений
- **USV.cpp/h** — Основной файл приложения
- **StdAfx.h/cpp** — Предкомпилированные заголовки (precompiled headers)
- **resource.h** — Заголовок с определениями ресурсов

### Конфигурационные файлы

- **StandDir.cfg** — Конфигурация стандартных директорий
- **USV.frm** — Файл формы
- **USV.dsp/USV.dsw** — Файлы проекта Visual Studio 6.0

### Ресурсы

- **res/** — Директория с ресурсами приложения (иконки, курсоры, bitmap и т.д.)
- **USV.rc** — Файл описания ресурсов
- **shared/** — Общие ресурсы или библиотеки

## Сборка и компиляция

### Требования

- Microsoft Visual C++ 6.0 или совместимая среда разработки
- Windows SDK с поддержкой MFC

### Инструкция по сборке

1. Откройте файл `USV.dsw` в Visual Studio 6.0
2. Выберите конфигурацию сборки (Debug/Release)
3. Соберите проект через меню Build → Build USV.exe

## Использование

После успешной компиляции запустите исполняемый файл USV.exe для работы с приложением.
